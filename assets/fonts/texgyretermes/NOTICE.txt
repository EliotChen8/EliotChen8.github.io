Changes made for this site:
  The four OpenType (.otf) files were repackaged as WOFF2 with fontTools.
  This is a container conversion only. After decompressing, every font table
  is byte-identical to the original OTF except two bookkeeping fields in the
  'head' table (checkSumAdjustment, and flags bit 11, which the WOFF2
  specification requires to be set). No glyphs, metrics or names were changed,
  and no subsetting was done. Font names and the original file base names are
  kept, as in the upstream distribution.

The original README-TeX-Gyre-Termes.txt and MANIFEST-TeX-Gyre-Termes.txt are
included unchanged.
